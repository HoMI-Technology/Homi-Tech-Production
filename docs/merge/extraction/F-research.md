## PART 3 — BUILD IMPLICATIONS (finding → concrete product action)

1. **G1 conflict-of-interest gap → monetization architecture.** Never sell consumer financial products or take affiliate revenue; revenue = subscriptions + employer PEPM + B2B API. Surface this as a trust feature in-product ("we make money when you get clarity, not when you transact"). Pitfall to avoid: any future affiliate/lead-gen deal destroys the core positioning.
2. **G2 three-pillar blind spot → scoring engine is the moat.** Build Financial Reality + Emotional Truth + Perfect Timing as a deterministic 0–100 score with frozen, version-controlled canon; AI explains, never computes. Verdicts: READY / ALMOST THERE / BUILD FIRST / NOT YET. Canon threshold: ALMOST THERE = 60–74 (fix landing page's stale 65–79).
3. **G3 "permission to wait" → the NOT YET verdict is the product's soul.** Design NOT YET as empowering (progress plan, re-assessment in 30 days — the cron exists), never as rejection. All copy: "Not yet is not no." Avoid any UX that nudges users to retake immediately or shop loans after a low verdict.
4. **G4 hidden-cost crisis → build total-cost-of-ownership education into the assessment.** The $18,000/yr hidden-cost figure, 42% maintenance-regret stat, and 25% insurance-blindness stat justify a concrete "true monthly cost" module (mortgage + maintenance + insurance + taxes + utilities) inside Financial Reality, plus an emergency-fund-gap flag. This is a differentiating calculator feature.
5. **G5 emotional override → Emotional Truth must detect pressure states.** 76% red-flag blindness, 10-minute attachment, FOMO stats justify questions/behavioral signals capturing urgency, external pressure, and decision fatigue. Guardrail: users under acute stress get conservative verdicts (scarcity reduces cognitive capacity ~13 IQ pts).
6. **G6 outcome moat → ship outcome surveys at day 30/90/365 from launch.** This is time-gated; every week of delay permanently delays the moat. Doc B: meaningful data at 1,000 users, category-defining at 10,000, institutional-grade at 100,000. Companion-delivered surveys for response rate. Initial thresholds deliberately conservative.
7. **G7 companion → relationship compounding.** Doc B maps personas to companion characters (Steady/Clarity/Horizon); Doc A names agents (Homie/Reality Check/Gut Check/Timing Advisor/Finance Planner + Guardrail). Reconcile naming before build. Companion v1 scope = assessment coach + results narration (highest impact per engineering hour); memory system post-launch = switching cost.
8. **G8 employer channel → measurable outcome reporting is the B2B wedge.** HR buyers need trackable scores over time (vs unmeasurable education). Build aggregate (privacy-safe) employer dashboards. $1–3 PEPM pricing; target mid-market in 7 high-cost housing metros.
9. **Viral loop → the Permissioned Readiness Summary is the growth engine.** Shareable, timestamped, HōMI-verified, expiring, revocable score receipt. Build for: social proof, authority transfer (borrowed credibility with agents/landlords), B2B lead discovery (every share view = API prospect). Targets: 20–30% of assessments → share; 5–15% of share views → signup. Consumer share system is already "70% of institutional infrastructure" — add API keys, webhooks, compliance dashboards, SLAs later.
10. **Positioning to adopt.** Category = "Decision Readiness Intelligence"; HōMI complements credit scores, never replaces them ("A credit score tells institutions if you may repay; HōMI tells you if you are ready"). This is both differentiation and a legal boundary (FCRA/UDAP exposure if used in lending decisions — keep "educational guidance only" posture in all B2B contracts).
11. **Launch wedge = Anxious First-Timer (38% of SAM, 25–35, $50–90K).** Channels: first-time-buyer subreddits, TikTok finance content, entry-level buyer agents. Content engine: "score yourself" quiz-style videos with real score receipts; 20–30 micro-influencers at $500–2,000 each; <$5 cost per assessment start.
12. **Pitfalls catalog (from competitor autopsies).** Credit Karma: affiliate incentives corrupt recommendations. NerdWallet: feature removal + bait-and-switch erodes trust. Opendoor: $62M FTC lesson — never let speed/volume optics override consumer outcome. Rocket: "fast mortgage" branding = readiness-blind. Mint→Credit Karma migration: acquired tools get strip-mined — position HōMI as acquisition-proof trust brand.
13. **Sequencing (merged from both docs).** (0) Fix canon threshold bug + env vars + og image (<1 day). (1) DTC launch with companion v1 + share loop + outcome surveys. (2) Months 12–24: B2B API via 3 originator pilots ($50K) + 10 regional CUs ($5K). (3) Months 18–36: companion memory + family mode + category ownership (Money 20/20, MBA Annual, white papers).
