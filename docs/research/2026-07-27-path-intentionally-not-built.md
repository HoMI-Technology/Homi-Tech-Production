# Intentionally not built (product discipline)

As of Path to Ready sprints, HōMI **does not** ship:

| Feature | Why not |
|---------|---------|
| Bill negotiation with **success fees** (35–60% of “savings”) | Trust liability; Rocket Money’s primary complaint surface |
| Cancel-for-you concierge | Ops/liability war; not Decision Readiness |
| Action marketplace with contingency fees | Same fee-shock failure mode |
| Subscription killer that calls providers as you | Creepy/authorization risk |

## What we ship instead

- **Subscription-like capacity drag** from Plaid categories (awareness + monthly estimate)
- **Recurring capacity** manual + bank-heuristic lists on `/path`
- **Path funding** and scenario wait-plans (you fund; we don’t extract savings)
- Transparent **subscription education** — never a surprise success fee

This is deliberate brand protection: *Am I ready?* not *Where is money leaking?*
