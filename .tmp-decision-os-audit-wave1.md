## Executive summary

HōMI has a strong, deterministic core — a single scoring engine, a well-tested Canonical Financial Model (CFM), source-labeled inputs, local-first sync, and server-side entitlements. The backend pieces of a Decision Intelligence OS are largely in place.

The product, however, still presents itself as a directory of tools and pages. Navigation exposes ~19 signed-in destinations. Scenarios live in three independent subsystems that can contradict each other. The most-trafficked AI surface (`/api/advisor`) has no automated output guardrail. Verified bank data is walled off from the Decision Lab tools. And several UI honesty contracts (source tags, chain hand-offs) are partially implemented but broken in specific lenses.

This synthesis combines findings from four specialist audits plus direct spot-checks of cited code.

## Critical findings (ranked by user impact)

### 1. Main Companion route has no automated guardrail enforcement
- **File:** `app/api/advisor/route.ts`
- **Issue:** Model replies are returned directly to users. `sentinelCheck()` exists in `lib/agents/registry.ts` but is only wired into the experimental Agent OS route. No output parser, refusal detector, or rewrite-on-flag protects the primary AI surface.
- **Risk:** Jailbreaks, sycophantic responses, or hallucinated advice can reach users unimpeded.
- **Fix:** Apply `sentinelCheck(reply)` (or equivalent) to `/api/advisor`; on flag, serve deterministic fallback or append visible disclaimer. Add regression tests.

### 2. Decision surface is fragmented and can contradict itself
- **Files:** `lib/decisions/simulate.ts`, `lib/tools/scenarios.ts`, `lib/readiness/scenario.ts`, `lib/readiness/scenario-path.ts`
- **Issue:** Three scenario systems run independent math:
  - Scenario Studio models 5-year net position with appreciation/rent growth.
  - Decision Lab lens scenarios compare static obligations against the saved CFM snapshot.
  - Readiness simulator anchors to stored pillar scores.
  There is no reconciliation layer warning users when models disagree.
- **Risk:** A user can be told "wait-12 is best" in one surface and "buy House A now" in another.
- **Fix:** Unify assumptions behind a single decision model, or clearly label each scenario as independent/illustrative with explicit assumption diffs.

### 3. Plaid verified data is walled off from the CFM
- **Files:** `lib/tools/cfm.ts`, `app/api/advisor/route.ts`, `lib/simulator.ts`, `app/[locale]/(product)/path/page.tsx`
- **Issue:** Dashboard, Path, and Simulator already consume verified bank data, but Decision Lab tools seed only from self-reported `lib/finance/store.ts`. `cfm.ts` has no `"plaid_sync"` source label.
- **Risk:** Same user sees different numbers across surfaces; tools may give guidance based on stale/inaccurate self-reported inputs despite authoritative bank data existing.
- **Fix:** Feed Plaid-derived snapshots into the CFM with a distinct `"plaid_sync"` source label so tools can prefill from verified numbers while preserving provenance.

### 4. Tool chain hand-offs are navigation-only
- **Files:** `lib/tools/registry.ts`, `components/tools/ChainLinks.tsx`
- **Issue:** `LensChain.carry` is declared in the registry but never consumed by `ChainLinks`. Clicking "See a real payment at this price" from Affordability lands on Mortgage with CFM seeds, not the specific price just viewed.
- **Risk:** Violates the promise of typed cross-lens hand-offs; breaks the "Decision Lab as a path" narrative.
- **Fix:** Implement `carry` by passing values via query params or overlay write-back before navigation.

### 5. Agent OS reports fake tool execution
- **Files:** `app/api/agents/route.ts`, `lib/agents/registry.ts`
- **Issue:** `toolsCalledForAgents()` maps routed agent names to static strings like `"monte_carlo_stress_test"`. No tool executor runs. The UI may display `tools_called` as if real simulations informed the answer.
- **Risk:** Trust gap; users may act on advice they believe was calculator-backed.
- **Fix:** Either implement real tool handlers behind a structured tool-calling schema, or remove/rename `tools_called` until it reflects actual execution.

### 6. Two lenses break the source-tag honesty contract
- **Files:** `app/[locale]/(product)/tools/debt-payoff/page.tsx`, `app/[locale]/(product)/tools/blind-budget/page.tsx`
- **Issue:**
  - `debt-payoff` bypasses `useLensPrefill` entirely and seeds via custom `useEffect`; no registry `inputs`; fallback debt rows are hard-coded.
  - `blind-budget` calls `useLensPrefill` but renders with custom `RangeField` that has no `source` prop, so "your numbers" tags are lost.
- **Risk:** Users cannot distinguish real inputs from illustrative placeholders.
- **Fix:** Convert `debt-payoff` to registry inputs + `LensField`; add `source` prop to `RangeField` / `blind-budget` inputs.

### 7. Prompt injection surface via stored/client-controlled strings
- **File:** `app/api/advisor/route.ts`
- **Issue:** `hardStops`, `path.boardMeetingLine`, `identity.name`, `surface`, and `whatChanged` are concatenated into the system prompt/context note without delimiters, escaping, or allowlisting.
- **Risk:** A compromised assessment row or crafted client payload could inject instructions.
- **Fix:** Wrap context blocks in XML tags; escape control characters; validate `surface` server-side; add prompt-injection regression tests.

### 8. Plaid data-retention and consent gaps
- **Files:** `app/api/plaid/disconnect/route.ts`, `supabase/migrations/00017_bank_sync.sql`, `supabase/migrations/00024_plaid_transactions.sql`, `app/api/advisor/route.ts`
- **Issue:**
  - Per-item disconnect deletes the local row even if `/item/remove` fails, potentially orphaning a live access token.
  - `plaid_transactions` and `plaid_accounts` are stored plaintext with no retention bound.
  - Verified cash flow is sent to Anthropic without recorded opt-in/disclosure.
- **Risk:** Privacy/compliance exposure; user believes data removed when bank linkage persists; full financial history exposed if DB/service key compromised.
- **Fix:** Fail closed on disconnect revocation (or tombstone + async retry); encrypt transaction/account payloads and implement retention policy; add explicit consent record before bank-derived data enters LLM prompts.

### 9. Navigation still exposes a feature directory
- **Files:** `lib/layout/app-nav.ts`, `components/dashboard/QuickActionGrid.tsx`
- **Issue:** App nav shows 3 primary + 16 "More" destinations (plus Agents when flagged). Dashboard quick actions grid lists 11 "All instruments".
- **Risk:** Product feels like a toolbox, undermining the "Decision Intelligence OS" positioning.
- **Fix:** Collapse nav to the proposed workspace shell (Today, Decisions, Path, Homie) and demote tools into contextual entry points.

### 10. Reproducibility gaps in deterministic outputs
- **Files:** `lib/readiness/path.ts`, `lib/readiness/scenario-path.ts`, `lib/tools/scenarios.ts`, `lib/simulator.ts`
- **Issue:** Path/scenario IDs use `crypto.randomUUID()` / `Math.random()`; simulator anchors to stored pillar scores rather than always recomputing.
- **Risk:** Identical inputs produce different output objects; determinism across time is not guaranteed.
- **Fix:** Derive IDs deterministically from inputs + timestamp; recompute simulator from stored inputs by default.

## Recommended remediation sequence

### Phase A — Safety & trust (do first)
1. Add output guardrail to `/api/advisor` (sentinel + fallback on flag).
2. Fix prompt-injection surface (delimiters, escaping, server-side validation).
3. Remove or rename fake `tools_called` in Agent OS.
4. Add explicit consent/disclosure before bank-derived data enters Anthropic prompts.

### Phase B — Coherence (highest product impact)
5. Collapse signed-in nav to a decision workspace shell.
6. Feed Plaid data into CFM with `"plaid_sync"` source label.
7. Reconcile scenario assumptions or clearly surface independence.
8. Implement `ChainLinks.carry` for real cross-lens hand-offs.

### Phase C — Polish & determinism
9. Convert `debt-payoff` to registry/prefill pattern; add `source` to `blind-budget` ranges.
10. Make path/scenario IDs deterministic; align simulator recompute behavior.
11. Fix Plaid plaintext storage + retention; harden disconnect revocation.
