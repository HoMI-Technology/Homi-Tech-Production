# Never-say (social + pixels)

| Never say | Say instead |
|-----------|-------------|
| You are approved / you qualify | Your readiness signal is favorable |
| You should buy now | Consider whether the timing supports this decision |
| Guaranteed | (remove) |
| Bank-level / military-grade security | We take privacy and security seriously |
| This is financial advice | This is educational guidance only |
| HōMI replaces your credit score | HōMI answers readiness — a different question |
| Pre-approved, pre-qualified, our lenders, best deal | (forbidden) |
| HōMI Score | Decision Readiness Score |
| HōMI Compass | Threshold Compass |

No fabricated metrics. No house photos / faces as brand identity. Educational guidance only.
