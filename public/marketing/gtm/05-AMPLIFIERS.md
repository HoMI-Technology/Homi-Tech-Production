# 5 · PH / press only after the engine runs

## Principle
Product Hunt, press, and directories **amplify** momentum. They do not create a business.

## Prerequisites before PH or big press
| Gate | Pass criteria |
|------|----------------|
| Activation | Assessment path works end-to-end |
| List | ~**400 engaged** emails if competing for PH attention (planning heuristic) |
| Demo | Real product path visible (prefer screen+voice over pure slideshow) |
| Assets | Gallery + thumb from SoT |
| Ops | `LAUNCH_DAY.md` pre-scheduled; founder on replies |

## Asset paths (SoT)
| Use | Path |
|-----|------|
| Launch Day checklist | `/marketing/gtm/LAUNCH_DAY.md` |
| PH brand gallery | `/marketing/launch/product-hunt/` |
| PH **live product** gallery | `/marketing/launch/product-hunt/gallery-live/` |
| Press kit | `/marketing/launch/press-kit/` |
| One-pager PDF | `/marketing/launch/press-kit/pdf/HOMI-One-Pager-Partners-Investors.pdf` |
| FAQ PDF | `/marketing/launch/press-kit/pdf/HOMI-FAQ.pdf` |
| Demo video | `/marketing/launch/demo-video/HOMI-Demo-60s.mp4` |
| Live screenshots | `/marketing/screenshots/live/` |

## Recommended order
1. Engine running (email + founder channel + activations)  
2. Soft launch to list  
3. PH / press spike  
4. Immediately back to engine (day +1)

## Do not
- Delay product fixes for PH cosmetics  
- Launch on 6 platforms with no reply plan  
- Optimize for upvotes over email capture / activation
