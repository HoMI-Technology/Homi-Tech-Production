# 1 · Activation is the score

## Principle
Vanity (followers, PH rank, impressions) is fuel. **Activation** is the score.

## Definition (HōMI)
An **activation** = a user completes a Decision Readiness path (assessment completed / primary readiness outcome delivered) on https://homitechnology.com.

## Funnel (measure weekly)
```
Visit → Waitlist/Signup → Account → Assessment completed (ACTIVATION) → Return / paid
```
Admin mirror: `/admin/marketing` funnel (Waitlist → Accounts → Completed assessment → Paid).

## North-star
**Weekly activated users** (count of new users who completed an assessment that week).

## Secondary (never primary)
- Waitlist signups  
- Social reach  
- PH upvotes  

## Actions
1. Fix anything that blocks assessment completion before buying ads.  
2. Every campaign asks: “Did this create activations?”  
3. Sunday scoreboard: activations + source of last 10.
